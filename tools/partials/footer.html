About

An open-source, interactive guide to the atom. Every number on this site comes from a cited measurement or is computed from physics in your browser. Nothing is made up for effect.

Source code on GitHub

Data

  • PubChem: element properties and descriptions
  • NIST Atomic Spectra Database: spectral lines, configurations, ionisation energies
  • IAEA LiveChart of Nuclides: half-lives, decay modes, masses
  • Wikipedia REST API: element summaries
  • CODATA 2018: physical constants
